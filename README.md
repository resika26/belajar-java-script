## 📌 Deskripsi Repositori
Repositori ini berfungsi sebagai **buku panduan, peta jalan (roadmap), dan tracker pribadi** dalam perjalanan menguasai pemrograman JavaScript dari tingkat paling dasar (*beginner*) hingga tingkat mahir (*pro/senior*).

---

## 🗺️ Tahapan Lengkap Menguasai JavaScript (Roadmap to Pro)

---

### 🟢 FASE 1: Fundamental & Logika dasar (Pemula)
> **Target:** Memahami sintaks dasar, tipe data, dan logika berpikir komputer.

1. **Aturan Dasar & Sintaks:**
   - Variabel: `const`, `let` (dan memahami mengapa `var` dihindari di JS modern).
   - Tipe Data Dasar: String, Number, Boolean, Null, Undefined, BigInt, Symbol.
2. **Struktur Data Dasar:**
   - **Array:** Membuat daftar data, memahami indeks, dan perintah dasar (`push`, `pop`, `shift`, `unshift`).
   - **Object:** Menyimpan data pasangan kunci-nilai (*key-value pairs*).
3. **Logika Kontrol & Perulangan:**
   - Pengondisian: `if`, `else if`, `else`, `switch`, dan *Ternary Operator* (`kondisi ? ya : tidak`).
   - Perulangan: `for`, `while`, `do-while`, `for...of`, dan `for...in`.
4. **Fungsi (Functions):**
   - Deklarasi Fungsi, Parameter, Argumen, dan *Return Value*.
   - *Arrow Functions* (`() => {}`).
5. **Manipulasi Data Sederhana:**
   - Manipulasi Teks (String Methods): `.length`, `.indexOf()`, `.slice()`, `.toUpperCase()`, `.toLowerCase()`.

---

### 🟡 FASE 2: JavaScript Modern (ES6+) & Array Advanced (Menengah)
> **Target:** Menulis kode yang efisien, bersih, dan sesuai standar industri.

1. **Higher-Order Array Methods (Wajib Kuasai):**
   - `.map()` : Mengubah seluruh isi array menjadi bentuk baru.
   - `.filter()` : Menyaring elemen array berdasarkan kondisi tertentu.
   - `.reduce()` : Mengolah/mengakumulasi seluruh isi array menjadi 1 nilai tunggal.
   - `.find()`, `.findIndex()`, `.some()`, dan `.every()`.
2. **Fitur JS Modern (ES6+):**
   - **Destructuring:** Mengekstrak nilai dari Array/Object secara cepat.
   - **Spread & Rest Operator (`...`):** Menggabungkan atau menyalin data dengan mudah.
   - **Template Literals:** Menggunakan string dinamis dengan backtick (`` `${variabel}` ``).
3. **Cakupan & Lingkup Variabel (Scope & Closure):**
   - Global Scope vs Local Scope.
   - **Closure:** Pemahaman tentang bagaimana fungsi dapat mengingat variabel di luar lingkupnya.

---

### 🟠 FASE 3: Interaksi Web & Asynchronous JS (Lanjut)
> **Target:** Mampu membuat web interaktif dan berkomunikasi dengan server/API.

1. **DOM (Document Object Model) Manipulation:**
   - Memilih elemen HTML (`querySelector`, `getElementById`).
   - Mengubah isi teks, HTML, dan styling via JS.
   - Menangani kejadian/aksi pengguna (*Event Listeners*: `click`, `submit`, `keyup`).
2. **Asynchronous JavaScript:**
   - Memahami perbedaan *Synchronous* dan *Asynchronous*.
   - `setTimeout` & `setInterval`.
   - **Promises:** Memahami status *Pending*, *Fulfilled*, dan *Rejected*.
   - **Async / Await:** Penulisan kode asynchronous yang lebih rapi.
3. **Komunikasi Data (Fetch API & Axios):**
   - Mengambil (*request*) data dari API eksternal (JSON format).
   - Menangani error pada koneksi jaringan (*Try...Catch*).

---

### 🔴 FASE 4: Arsitektur & Cara Kerja Dalam JS (Pakar / Pro)
> **Target:** Memahami mekanisme di bawah kap mesin JS untuk performa aplikasi yang optimal.

1. **Konsep & Cara Kerja Dalam (Under the Hood):**
   - **Event Loop, Call Stack, Task Queue, & Microtask Queue.**
   - **Hoisting** & **Execution Context**.
   - **Prototype & Prototypal Inheritance.**
2. **Paradigma Pemrograman:**
   - **Object-Oriented Programming (OOP):** Class, Constructor, Inheritance, Encapsulation.
   - **Functional Programming (FP):** *Pure Functions*, *Immutability*, *Side Effects*.
3. **Penyimpanan Lokal Browser:**
   - `localStorage`, `sessionStorage`, dan `Cookies`.
4. **Modul & Perkakas (Tooling):**
   - ES Modules (`import` / `export`).
   - Node.js Environment & NPM (Node Package Manager).

---

### 🟣 FASE 5: Spesialisasi & Ekosistem Industri (Expert)
> **Target:** Siap bekerja secara profesional sebagai Senior/Full-Stack Developer.

1. **TypeScript:** Menambahkan sistem tipe data ketat pada JS untuk mencegah bug skala besar.
2. **Frontend Framework:** Menguasai salah satu framework populer (React.js, Vue.js, atau Next.js).
3. **Backend dengan JS:** Membangun RESTful API atau GraphQL Server menggunakan Node.js & Express.js.
4. **Testing & Security:**
   - *Unit Testing* & *Integration Testing* menggunakan Jest atau Vitest.
   - Menjaga keamanan dari celah XSS, CSRF, dan kebocoran memori (*Memory Leaks*).

## 💡 Strategi Belajar Efektif (80/20 Rule)

1. **20% Teori, 80% Praktek:** Jangan terlalu lama menonton tutorial video. Langsung ketik dan eksplorasi kodenya di VS Code.
2. **Pahami Logika, Bukan Menghafal:** Pahami **mengapa** suatu kode bekerja, bukan sekadar menghafal sintaksnya.
3. **Rutin Commit & Push:** Dokumentasikan setiap perkembangan belajar ke GitHub sebagai rekam jejak portofolio secara konsisten.
